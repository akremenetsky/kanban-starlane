# Board header buttons

Hide any of the buttons shown in a board's header. All are on by default:

- **Add a list**
- **Archive completed cards**
- **Open as markdown**
- **Open board settings**
- **Search…**
- **Filter** — filter cards by tags and boards, see
  [Filtering by tags and boards](../guide/cards-and-lists.md#filtering-by-tags-and-boards)
- **Board view**
