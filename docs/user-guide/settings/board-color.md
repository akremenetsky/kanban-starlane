# Board color

The color that marks this board's cards when other boards show them through [linked
lists](../guide/linked-lists.md) — they get a stripe of this color at the bottom.

This setting exists only in a board's own settings (its `⋮` menu or **Open board settings**
header button), not in the global settings. A board without a color gets one automatically; it
stays the same for that board from then on.
