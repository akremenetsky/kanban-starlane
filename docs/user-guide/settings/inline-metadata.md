# Inline metadata

Fields added by the [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) and
[Dataview](https://github.com/blacksmithgu/obsidian-dataview) plugins directly on a card's line
(e.g. a Tasks due date, or a `key:: value` Dataview field).

## Inline metadata position

Where Dataview's inline fields are shown on the card:

- **In the card text** — inline with the rest of the card's text.
- **Below the card text** — on a line below the text, separate from it.
- **Merge with linked page metadata** — alongside fields from [Linked page
  metadata](linked-page-metadata.md), in the same block.

Set to **Below the card text**:

## Show task data below the card text

When on, data added by the Tasks plugin (due dates, recurrence, priority, …) is shown on a line
below the card text instead of inside it.
