# Quick actions

When the mouse pointer is over a card, a small panel of buttons appears in its top-right
corner. The last button, `⋮`, opens the card menu, the same menu as a right-click. Pick up to
five actions to show before it:

| Action | What it does |
|---|---|
| **Mark as done** (on by default) | Checks the card, or unchecks a checked one |
| **Add or change date** (on by default) | Opens the calendar |
| **Set size** | Opens the list of [card sizes](card-size.md) |
| **Move to next list** (on by default) | Moves the card to the top of the list on the right; unavailable in the last list |
| **Move to list** | Opens the list of lists to move the card to |
| **Open or create note** | Opens the note the card links to, or creates one from the card, like [New note from card](../guide/cards-and-lists.md#creating-a-note-from-a-card) |
| **Archive card** | Moves the card to the archive |
| **Duplicate card** | Adds a copy of the card below it |

The buttons keep this order. Once five are on, the others cannot be switched on until one is
switched off. In a board's settings, the reset button next to the description goes back to
the global choice.

On cards from [linked lists](../guide/linked-lists.md) the panel shows the buttons of the board
you are looking at. **Move to next list** is unavailable there: the next list is in the card's
own board and may not be shown on this one; use **Move to list** instead. Phones and tablets have no pointer to hover with: there the card keeps its
`⋮` button, as before.
