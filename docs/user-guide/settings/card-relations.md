# Card relations

Relations between cards of the same board: *blocks*, *relates to*, *duplicates*, *causes* and
*depends on*. How to add and use them: [Card relations](../guide/cards-and-lists.md#card-relations).

## Card relations

On by default. Shows the *Blocked* mark and the number of relations on cards, and the actions
that add relations (card menu, quick action).

When off, relations are hidden but stay in the board file; switching back on shows them again.
